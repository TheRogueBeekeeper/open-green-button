# Fortis Ontario (Ontario, Canada)

## Provider

Green Button services for Fortis Ontario are provided by Savage Data.  Fortis is the parent company of:

* Algoma Power
* Canadian Niagara Power
* Cornwall Electric
* Eastern Ontario Power

Each is listed as its own utility (via `brands` in `utilities.conf`), but all share the single
`fortis_ontario` registration.

## Information on File

Registration created by William Seaton (@william-seaton) using his own contact information.
See https://github.com/rocketraman/open-green-button/issues/67.
